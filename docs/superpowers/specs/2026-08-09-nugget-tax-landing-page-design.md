# 너겟 세무사 랜딩페이지 설계

## 배경 및 목표

너겟(nugget)은 세무사 사무소를 위한 카카오톡 브랜드메시지 콘텐츠 서비스("너겟 세무사")를 운영한다. 이 프로젝트는 해당 서비스를 세무사에게 소개하고 리드를 확보하기 위한 정적 랜딩페이지를 구축한다.

**핵심 전환 목표**: 방문자가 "무료 샘플 1건 받아보기" 폼을 제출하도록 유도한다. 계약 전 부담 없이 실제 발송 화면 샘플을 받아볼 수 있다는 저마찰 제안으로 리드를 확보한다.

**참고 자료**:
- `브랜드메시지 상품 소개서(ver.2607).pdf` — 최종 매체소개서 (섹션 구조, 요금제 확정안)
- `브랜드메시지 디벨롭.xlsx` 중 `매체소개서 플로우`, `1차 수정`, `2차 수정` 시트 — 카피 개발 과정, 문제 정의/효익 메시지
- `브랜드메시지 디벨롭.xlsx` 중 `브랜드메시지 샘플` 시트의 이미지(image5, image8, image13 등) — 실제 카카오톡 브랜드메시지 발송 목업
- `샘플 제작 ver0806.docx` — 실제 발송용 콘텐츠 원고 샘플
- https://alimtalk.kr — 유사 업종(세무사 알림톡 대행) 레퍼런스 사이트

## 아키텍처

- **Next.js 15 (App Router) + TypeScript + Tailwind CSS**
- 단일 페이지 애플리케이션: `app/page.tsx`가 섹션 컴포넌트를 순서대로 조립
- 섹션 컴포넌트: `components/sections/` 아래 `Hero`, `Problem`, `SocialProof`, `WhyItWorks`(전략적 3효익), `HowItWorks`(운영적 3특징), `ContentExample`(실제 목업 재현), `Process`(3단계), `Pricing`, `FinalCta`(폼), `Footer`
- 공용 UI 요소(버튼, 카드, 섹션 래퍼)는 `components/ui/`에 둔다
- 폼 제출: `app/api/contact/route.ts` (Server Route Handler)
  - 요청 바디를 zod로 검증
  - Resend API로 `won@nugget.im`에 알림 메일 발송, 제출자 이메일을 `reply-to`로 설정
  - 환경변수: `RESEND_API_KEY`, `CONTACT_EMAIL_TO` (기본값 `won@nugget.im`)
- Git: 로컬 저장소를 초기화하고 `origin`을 `https://github.com/nugget-letter/tax.git`로 연결한다. **원격 저장소로의 push는 사용자 확인 후 실행한다.**
- 배포: Vercel을 전제로 하되, 실제 프로젝트 연결/배포는 이번 스코프에 포함하지 않는다 (별도 확인 후 진행).

## 페이지 구성 및 카피 방향

기존 PDF 순서에 xlsx에서 발견한 문제 정의·효익 메시지를 추가로 반영한 순서:

1. **헤더**: 로고 + "무료 샘플 받기" 버튼(폼 섹션으로 스크롤)
2. **히어로**: "세무사님 대신, 너겟이 매달 콘텐츠를 만들어 보내드립니다" + 서브카피 + CTA
3. **문제 정의** (신규): "고객이 세무사님을 찾는 건, 1년에 손에 꼽을 정도입니다" — 신고 시즌 후 연락 단절 → 고객이 타 세무사 광고를 보게 됨 → "접점이 없으면 관계도 없습니다"
4. **사회적 증거**: "2,450만명의 고객을 가진 삼쩜삼도 꾸준히 카카오톡 메시지를 보냅니다" + 채널 차별화 논리("카카오톡은 매일 열어봅니다")
5. **왜 효과적인가 (전략적 효익 3가지, 신규)**: 고객 이탈 방지 / 전문성 있는 브랜딩 / 신규 상담 전환
6. **어떻게 운영되는가 (운영적 특징 3가지, 기존 PDF)**: 직접 쓸 필요 없어요 / 지속적인 접점 확보 / 자동으로 발송해요
7. **콘텐츠 예시**: 실제 카카오톡 브랜드메시지 목업 스타일(채널 헤더 + 이미지 + 본문 + 상담 버튼)을 HTML/CSS로 재현. 문구는 `샘플 제작 ver0806.docx`의 실제 원고(부가가치세 개정, 법인차 탈세 여부, 사업자 필수 체크 6가지) 중 2~3개를 선별해 사용
8. **제작 프로세스 3단계**: 콘텐츠 기획 → 콘텐츠 확인(발송 1주일 전) → 콘텐츠 발송
9. **요금제 3단**: Light 월2회 50만원 / Standard 월4회 95만원(추천 배지) / Premium 월8회 180만원(전담 에디터). 각 카드 CTA는 "이 플랜으로 문의하기" → 폼에 플랜 값 미리 채움
10. **최종 CTA + 폼**: "지금, 콘텐츠 1건을 무료로 받아보세요" — 계약 전 실제 발송 화면 샘플 무료 제작 제안. 필드: 세무사/사무소 이름*, 연락처*, 이메일*, 관심 플랜(선택), 하고 싶은 말(선택)
11. **푸터**: 회사 정보(주식회사 너겟), 연락처

## 비주얼 디자인

- 다크 네이비/블랙 배경(히어로, 문제 정의, 사회적 증거 섹션) + 오렌지→레드 그라데이션 포인트(로고 톤과 통일) + 흰 카드 섹션(효익/특징/프로세스/요금제)
- 콘텐츠 예시 섹션은 실제 카카오톡 UI를 모사한 폰 프레임 목업(채널명 헤더, 말풍선, 이미지, 노란색 CTA 버튼 등 스크린샷에서 확인된 스타일 반영)
- 굵은 산세리프 헤드라인, PDF와 동일한 톤앤매너 유지

## 폼 처리 & 에러 핸들링

- 클라이언트: 필수값/이메일 형식 검증, 제출 중 로딩 상태, 성공/실패 인라인 메시지
